# ComfyUI-DJ_GroupTitle

> 版本 `260911-075054` · 作者：大江

ComfyUI 组标题增强插件：**字号 / 对齐 / 颜色** 三件套。纯前端实现，不注册画布节点，不参与推理，装上去只影响画布上「组」的标题交互。

## 文件结构

```text
ComfyUI-DJ_GroupTitle/
├── __init__.py                 ← 纯前端注册：NODE_CLASS_MAPPINGS 为空，只声明 WEB_DIRECTORY
├── README.md
└── web/
    └── js/
        └── dj_group_title.js   ← 全部功能逻辑（注册扩展 dajiangtools.group_title）
```

## 功能速览

| # | 功能 | 说明 |
|---|------|------|
| 1 | 字号横条 | 左键单击组标题弹出浮条，拖动横条实时改字号，范围 `12`–`300 px`（默认 `20`） |
| 2 | 多组同步 | 多选组后，字号 / 对齐 / 颜色一次改全部；**嵌套组只作用于最外层**，不会被改两遍 |
| 3 | 自动避让 | 标题放大后若与下方节点或子组间距不足，组自动向上扩展，**恒定保留 `24 px` 间距** |
| 4 | 标题对齐 | 左对齐 / 居中 / 右对齐，画布与重命名编辑框同步生效 |
| 5 | 组颜色增强 | 实时预览 + **63 种预设颜色**网格 + 自定义取色器 |
| 6 | 标题文字独立调色 | 单独调**饱和度**与**明度**，色相自动跟随组颜色 |
| 7 | 改色即换色相 | 更换组颜色后，标题文字自动切换到相同色相 |
| 8 | 随工作流保存 | 字号、对齐方式、标题颜色全部写入工作流 JSON，重开不丢 |

## 操作方式

### 1. 调字号：左键单击组标题

**在组标题上左键单击**（松手即弹出，无延迟）→ 画布上浮出**字号横条**，横条会跟着这个组走，缩放 / 平移画布都不会脱离。

横条上有两样东西：

- **进度条**：在它上面**按住左键左右拖动**，实时改字号
- **数字输入框**：直接键入精确值，回车提交

关于范围，有个细节值得说清：

- 字号真实有效范围是 **`12`–`300 px`**，默认 `20`
- 横条的进度条**视觉上只映射 `12`–`96 px`**，所以想上到 96 以上（做超大字标题）请用**数字输入框**直接输

其他行为：

- **拖动组标题 ≠ 弹横条**。拖标题是原生「移动这个组」，插件不抢这个手势，也不会弹条
- **双击组标题** = 原生重命名编辑框（此时不弹横条），编辑框里的字号与对齐会跟着当前设置走
- 按 **`Esc`** 关闭横条，并放弃这次改动
- 横条打开期间，ComfyUI 原生的「选中工具栏」会被自动压住，免得挡住横条

### 2. 组标题右键菜单

在组标题上**单击右键**打开原生菜单，插件往里加了 / 换了两项：

| 菜单项 | 作用 |
|--------|------|
| **标题色** | 打开 HSV 取色面板：**色相跟随组颜色**，饱和度 / 明度各自独立可调；带「清除」按钮还原默认标题色 |
| **组颜色** | 63 色网格（7 列）+「自定义取色」；**鼠标滑过色块即时预览**，**左键点击色块立即写入并关掉菜单**（没有二次确认按钮）；直接关掉菜单则自动还原成原色；第一项「无颜色」= 清除组颜色 |
| **标题对齐** | 左 / 居中 / 右，选中即生效（位置在「字号」项下面） |

### 3. 批量改多个组

按住 `Ctrl` / `Shift` 多选若干个组，再对其中任意一个组操作（弹横条、改对齐、改颜色）→ **所有选中的组同步生效**。

- 嵌套组（组里套组）只改**最外层**那一个
- 多选组时**不会把组里的子节点一起选进去**（插件专门做了清理），所以不会冒出一堆节点工具栏

## 工作流保存的字段

| 字段 | 含义 | 取值 |
|------|------|------|
| `font_size` | 标题字号 | 数字，单位 px，`12`–`300` |
| `title_align` | 标题对齐 | `left` / `center` / `right` |
| `title_color_saturation` | 标题文字饱和度 | `0` ~ `1` |
| `title_color_brightness` | 标题文字明度 | `0` ~ `1` |

组颜色本身写在 ComfyUI 原生的 `color` 字段里，不是本插件新增的字段。

补充两点实现口径：

- 标题的**色相不单独保存**，由组自身的 `color` 推导 —— 这正是「改组颜色，标题自动跟色相」的原理
- 老工作流里若存过绝对色值字段 `title_color`，载入时会自动换算成饱和度 / 明度并迁移，设置不丢

## 安装

把整个 `ComfyUI-DJ_GroupTitle` 文件夹放进：

```text
ComfyUI/custom_nodes/
```

重启 ComfyUI，然后按 `Ctrl + F5` 强制刷新前端（前端 JS 有缓存）。

## 卸载

删掉 `custom_nodes/ComfyUI-DJ_GroupTitle` 文件夹即可，不影响任何已有工作流 —— 组标题那几个扩展字段只会被忽略，组照常按默认样式显示。

## 注意

- **不要与其他「组标题增强类」补丁同时启用**：不同补丁的防重入标记互不认账，会各打一遍补丁，表现为右键菜单出现两组「标题色 / 组颜色 / 标题对齐」、画布上叠出两条字号横条。
- 本插件自身带防重入标记（`djGroupTitleInstalled` 等），重复加载会自动跳过，不会自己叠自己。
